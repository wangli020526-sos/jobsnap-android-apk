# 职捕 JobSnap — Android 原生全局跨 App 悬浮侧边栏 APK 工程

本工程是完整的 Android 原生（Kotlin）项目源码，已为您配置好：
1. **全局跨 App 贴边可折叠悬浮窗（`SYSTEM_ALERT_WINDOW`）**：可悬浮在 BOSS直聘、猎聘、前程无忧、拉勾等任意招聘软件上方，平时可收起为屏幕右侧微缩胶囊，点击展开四个按钮：「识别岗位信息」、「识别业务公司」、「加入意向岗位」、「标记已投递」。
2. **安卓无障碍屏幕文字抓取（`AccessibilityService`）**：点击按钮时免截屏直接读取当前招聘软件屏幕上的全部岗位职责、任职要求与公司介绍文字，发往云端 AI 实时提炼并弹窗展示。
3. **内置投递管理总表 WebView 主界面（`MainActivity`）**：打开 App 即可管理并导出包含「公司、岗位、薪资、保存日期、投递日期、状态」的求职追踪表格。

---

## 零配置云端自动编译并发布独立 `.apk`（手机浏览器点开链接直接一键下载安装！）

工程内已内置 **GitHub Actions 自动打包 + GitHub Releases 自动发布工作流**（`.github/workflows/build-apk.yml`）：
1. 当代码同步到您的 GitHub 仓库后，GitHub 云端服务器会自动启动 JDK 17 + Android SDK 编译。
2. 编译完成后（约 2 分钟），会自动在您仓库的 **Releases（发行版）** 页面发布独立的 **`JobSnap-v1.0.apk`** 文件（非压缩包！）。
3. 您用安卓手机浏览器打开 `https://github.com/您的用户名/仓库名/releases/latest`，直接点击 **`JobSnap-v1.0.apk`** 即可下载并一键安装到手机！

---

## 手机安装后的首次开启步骤

1. 在安卓手机安装并打开 **「职捕 JobSnap」** App。
2. 点击界面顶部的 **「1.开启悬浮窗权限」**，在系统设置中允许「显示在其他应用的上层」。
3. 点击 **「2.开启无障碍抓词」**，在系统「无障碍 / 已下载的应用」中找到 **「职捕AI侧边栏采集服务」** 并开启。
4. 开启后，屏幕右侧边缘即会出现可折叠的 **「职捕AI栏」**，现在您可以打开 **BOSS直聘 / 猎聘** 边刷岗位边点击采集了！
